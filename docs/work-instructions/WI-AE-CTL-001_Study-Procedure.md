# Cycle Time & Labor Study — Work Instructions

## 1. Define the Study

Record the line, product/job, date, shift, observer, and applicable rate references.

## 2. Build the Process Structure

Define the production hierarchy before collecting a large sample set:

1. Role or station
2. Task
3. Element or sequence step

Identify support work separately from paced production work when appropriate.

## 3. Define Relationships

Record how often each process occurs relative to the reference unit. Capture material-use relationships and replenishment context where required for downstream planning.

## 4. Capture Timing

Select the role/task/element being measured and collect representative observations. Use sequential capture when the order of standard work matters.

## 5. Validate the Dataset

Review:

- Missing setup information
- Low sample counts
- Timing outliers
- Sequence reconciliation
- Operator/position variation
- Process frequency assumptions

## 6. Analyze

Review role timing, process pace against the throughput/takt reference, Yamazumi balance, support workload, and placement opportunities.

## 7. Save and Export

Save the editable study JSON and export the analysis/report JSON required by downstream tools.
