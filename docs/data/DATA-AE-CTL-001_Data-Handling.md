# Cycle Time & Labor Study — Data & Privacy

The study tool can save editable study data and export analysis/report data for downstream use.

Recommended practice:

- Retain the editable study JSON.
- Retain the report JSON used by downstream planners or analyzers.
- Keep important study outputs together with the tool/app version.
- Avoid unnecessary personal information in operator labels or notes.
- Follow site requirements for production, employee, and customer data.
