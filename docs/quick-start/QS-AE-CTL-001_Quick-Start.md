# Cycle Time & Labor Study — Quick Start

## Typical Workflow

1. Create or load a study.
2. Complete the study identity and throughput-reference information.
3. Build the **Role → Task → Element** process hierarchy.
4. Configure process frequency and material relationships.
5. Select a station/task and capture timing observations.
6. Use one-shot or sequential capture as appropriate.
7. Review **Study Readiness & Data Quality**.
8. Review timing outliers before excluding anything.
9. Review process pace, labor summary, and Yamazumi balance.
10. Save the study and export the analysis report.

## Sampling Guidance

Capture enough representative cycles to understand normal variation. Do not remove a sample only because it is long; first determine whether it represents a mistake, an abnormal event, or valid process variation.
