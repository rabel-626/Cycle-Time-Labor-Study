# Cycle Time & Labor Study — Methodology

## Representative Sampling

Timing data should represent the process conditions being studied. Capture normal process variation rather than only ideal cycles.

## Mean and Percentile Statistics

The mean describes average observed timing. Percentile statistics such as P90 can be useful when evaluating variability and conservative planning assumptions.

## Process Frequency

A timing observation is not automatically equal to seconds per finished unit. The process relationship must reflect how many process events occur per reference unit.

## Parallel Positions

Where equivalent work is performed in parallel, capacity interpretation should account for the number of active positions.

## Support Work

Recurring support work should be kept identifiable so it can be analyzed without incorrectly treating every support event as a paced operation.
