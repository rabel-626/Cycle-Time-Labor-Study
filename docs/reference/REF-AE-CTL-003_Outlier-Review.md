# Cycle Time & Labor Study — Outlier Review

## Purpose

Outlier review helps identify samples that deserve human review without automatically deleting unusual observations.

## Review Questions

For each flagged timing sample, determine whether it represents:

- A missed click or capture error
- A process interruption
- Rework or abnormal handling
- Legitimate long-cycle variation
- A different product or operating condition

## Exclusion Principle

Exclude a sample only when there is a defensible reason that it should not represent the studied process. Preserve notes or review status where possible.

> Statistical distance from the median is a review trigger, not proof that a sample is invalid.
