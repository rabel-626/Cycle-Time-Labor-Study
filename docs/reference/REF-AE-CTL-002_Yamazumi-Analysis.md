# Cycle Time & Labor Study — Yamazumi Analysis

## Purpose

A Yamazumi view stacks work content by role or position so workload can be compared to the available cycle/takt window.

## Interpretation

- A role above the reference line requires attention before the target rate can be considered sustainable.
- A role well below the line may have recoverable capacity, but physical access and task compatibility still matter.
- Color segmentation helps show where the work content originates.

## Engineering Review

Do not rebalance solely from chart height. Consider walking, reach, ergonomic constraints, machine interaction, quality checks, safety, and whether tasks can physically occur in the available work window.
