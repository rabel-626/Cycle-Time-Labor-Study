Machine Pace Verification

Measure Belt Speed

Recommended method: mark or identify one point on the belt, measure a known distance along the conveyor, tap START as that same point crosses the first reference, and tap STOP as it crosses the second. Longer distances reduce reaction-time error.
Synchronization check: Expected belt speed = machine target CPM × configured pitch distance. Current feed ratio = measured speed ÷ expected synchronized speed. VFD frequency estimates assume belt speed is approximately proportional to VFD Hz for the current motor / gearbox / conveyor setup.
