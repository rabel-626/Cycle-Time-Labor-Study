Reference Throughput & Machine Pace

Reference throughput basis: 1 Carton. Define all process relationships against this unit; machine strokes, belt pitches, and process events remain separate physical events.
Enter the primary machine's displayed output directly in reference units/min when known. Conveyor speed + pitch is an independent belt check; Reference Units per Belt Pitch converts physical belt pitches into equivalent throughput.

Machine Pace Verification

Measure Belt Speed

Recommended method: mark or identify one point on the belt, measure a known distance along the conveyor, tap START as that same point crosses the first reference, and tap STOP as it crosses the second. Longer distances reduce reaction-time error.
Synchronization check: Expected belt speed = reference throughput rate ÷ reference units per pitch × configured pitch distance. Current feed ratio = measured speed ÷ expected synchronized speed. VFD frequency estimates assume belt speed is approximately proportional to VFD Hz for the current motor / gearbox / conveyor setup.
