Timing Outlier Review

Outliers are review candidates, not automatic errors. The detector uses comparable Role / Task + capture method + sequence revision groups. Normal included observations form the preferred reference. With 5–9 comparable observations only extreme values (<⅓× or >3× median) are flagged; with 10+ observations the tool also uses median-factor and robust MAD checks.
